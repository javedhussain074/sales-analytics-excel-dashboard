# 🚀 Quick Setup Guide

## Step 1 — Open the File

1. Download `Sales_Analytics_Project.xlsx`
2. Open using:
   - Microsoft Excel 2016+
   - Excel 365
3. Click **Enable Editing**
4. Click **Enable Content** if prompted

> ⚠️ Excel is recommended for the best chart experience.

## 🧾 Step 3 — Explore Raw Data

The dataset contains:

- **1,000 transaction records**
- **17 business-related columns**
- Data from **Jan 2023 to Dec 2023**

### Main Columns

| Column | Description |
|---|---|
| Order ID | Unique transaction ID |
| Date | Order date |
| Quarter | Q1 / Q2 / Q3 / Q4 |
| Region | North / South / East / West / Central |
| Sales Rep | Fictional sales representatives |
| Channel | Online / Retail / Distributor / Direct |
| Category | Electronics / Clothing / Furniture / Groceries / Sports |
| Revenue | Net revenue after discount |
| COGS | Cost of goods sold |
| Profit | Revenue minus COGS |
| Status | Completed / Pending / Returned / Cancelled |

### 🎨 Status Colour Codes

- 🟢 Green → Completed
- 🟡 Yellow → Pending
- 🔴 Red → Returned
- 🌸 Pink → Cancelled

# 📊 Step 5 — Create Your Own Pivot Table

1. Select any cell in **Raw Data**
2. Go to:
   `Insert → PivotTable`
3. Choose:
   `New Worksheet`
4. Drag fields into:
   - Rows
   - Values
   - Filters

### Suggested Setup

| Area | Field |
|---|---|
| Rows | Category / Region |
| Values | Revenue (Sum), Profit (Sum) |
| Filters | Quarter / Status |

You can also insert PivotCharts for quick visual analysis.

# 🛠 Troubleshooting

| Problem | Solution |
|---|---|
| Charts not visible | Click "Enable Content" |
| #REF! errors | Do not delete `_ChartData` sheet |
| Slow workbook | Close extra Excel files |
| Numbers showing as dates | Change cell format to Number |
